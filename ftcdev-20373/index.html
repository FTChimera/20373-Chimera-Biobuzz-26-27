Current source-backed takeaways

  • tele/TeleOp is the main match teleop and wires DualGamepad into Robot.periodic(State).
  • autos/Garden8 is the current autonomous entry and schedules the Garden preload plus intake path through PlanBuilder.
  • Mechanism subclasses implement periodic(State) and stop(); Robot aggregates and sequences them.
  • Vision owns Limelight results and explicit relocalization; IntakeBallPath owns the detector-to-path algorithm.
  • MathUtils.java is the shared math file used by path smoothing and coordinate conversion helpers.
  • Validation is split among Gradle build steps, JVM tests, Driver Station utilities, FTC SDK smoke tests, and Pedro tuning op modes.
