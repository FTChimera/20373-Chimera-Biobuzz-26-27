## Libraries
We use Pedro Pathing for consistent localization and path following and autos. Along with Pedro Pathing, we like to use Pedro's additional Ivy for easier auto programming using the command-based paradigm.

Learn more at [the Pedro Pathing Website](https://pedropathing.com)

## Gems
We are very proud of these software accomplishments:
- Insane Codebase organization and reusability (we have to switch one constant field in Constants.java, and the entire codebase recognizes the switch and adapts to the new robot)
- Path Planners: we have implemented Path Planner modules for a really customizable autonomous. (Each segment/module intakes from a location, comes back, and shoots, for a really continuous and customizable autonomous)
- Intake W Vision: Driver automation/autonomous routine; Uses the Limelight's neural network feature to detect game elements, uses trigonometry to figure out their location, and generates a path on the fly to pick them up
- Field organization and customizability: We used JTS for shape detection with field elements, such as the park zone or hive valid shoot positions, making scoring an automation.

Our software team has also made a few classes to make programming easier, during the offseason/preseason and the previous (DECODE, 2025-26) season. They are found in the library folder under teamcode.
