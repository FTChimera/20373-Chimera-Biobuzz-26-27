This landing page summarizes the source-backed architecture in TeamCode/src: current match entries, the aggregate robot lifecycle, planner and vision boundaries, Java math helpers, and present validation routes.

Architecture snapshot

  • tele/TeleOp is the main competition teleop built on LinearOpMode.
  • autos/Garden8 is the active autonomous entry built on iterative OpMode.
  • Robot aggregates configured mechanisms and drives the shared periodic(State) lifecycle.
  • PlanBuilder, Common, and AlliancePoses form the current reusable planner surface.
  • Vision and IntakeBallPath split camera ownership from detector-to-path generation.
  • DualGamepad is the competition input wrapper and MathUtils.java is the shared math hub.

Current match path

TeleOp creates a teleop robot and DualGamepad, restores Blackboard pose and alliance, starts teleop drive, then updates controllers and runs Robot.periodic(State) during the active loop.

Garden8 resets the Ivy scheduler, creates the robot, schedules PlanBuilder.startGardenPose(robot).shootPreloads().intakeGarden(), executes the scheduler every loop, parks near timeout, and preserves autonomous handoff through robot shutdown.
